# UFERSA Resolve

O **UFERSA Resolve** é um projeto desenvolvido para a disciplina de **Desenvolvimento Web**, com o objetivo de criar uma plataforma web para centralizar o registro, acompanhamento e gerenciamento de solicitações relacionadas à infraestrutura e aos serviços da UFERSA.

A proposta é oferecer à comunidade acadêmica um canal único e organizado para comunicar problemas encontrados no campus, permitindo que cada solicitação seja identificada por um protocolo e posteriormente acompanhada até sua resolução.

## Objetivo

Facilitar a comunicação entre a comunidade acadêmica e os setores responsáveis pela manutenção e infraestrutura da universidade, proporcionando maior organização, transparência e rastreabilidade das solicitações.

## Exemplos de solicitações

O sistema foi projetado para contemplar ocorrências relacionadas a:

- Elétrica e iluminação
- Climatização
- Hidráulica
- Mobiliário
- Equipamentos de sala e projetores
- Rede e Internet
- Limpeza e conservação
- Acessibilidade
- Estrutura predial
- Outros problemas de infraestrutura

## Perfis previstos

O projeto prevê diferentes níveis de acesso, incluindo:

- Discente
- Docente
- Técnico-administrativo
- Atendente/Técnico
- Gestor de setor
- Administrador

Cada perfil terá permissões específicas de acordo com suas responsabilidades dentro do sistema.

## Primeira etapa

A primeira entrega do projeto é dedicada à **identidade visual e estruturação da interface**.

Nesta etapa foram desenvolvidas telas demonstrativas para representar visualmente o funcionamento futuro da aplicação. As funcionalidades de autenticação, banco de dados, armazenamento e processamento das solicitações serão implementadas nas próximas etapas.
